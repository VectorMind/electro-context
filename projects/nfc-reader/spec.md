# NFC reader device specification

## Stated scope

An ESP32-C3 board with a 0.42-inch OLED and an Elechouse NFCModule V3 are the starting hardware. The project includes ESP32 firmware, electrical integration, a printed enclosure and public build documentation.

## Intake status

Module-specific details from the owner are pending. Interface selection, pin assignments, mechanical constraints and acceptance checks are open. The intake packet owns the first evidence-backed revision.
