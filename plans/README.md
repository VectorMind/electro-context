# Using plans

Use plans/YYYY-MM/DD/<topic>/ and list each active packet in [open.md](open.md). Start with plan.md for scope and exit checks. Add handoff.md for a receiving agent with a concrete first action. Write implementation.md when changes exist and test.md when durable validation evidence warrants it. Keep raw captures in Drive and disposable logs in the project cache. On closure, move the index entry to [closed.md](closed.md) with its result. A planning-only packet can close after its decisions and deliverables are recorded.
