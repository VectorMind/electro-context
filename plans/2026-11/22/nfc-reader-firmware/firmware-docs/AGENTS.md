# NFC reader firmware

Start with [WORKFLOW.md](WORKFLOW.md), the [reader specification](specification/reader.md) and the [bring-up plan](.plans/2026/11/22/reader-bringup/plan.md). This checkout owns ESP32-C3 firmware. The Electro device project owns the harness, electrical limits and bench evidence.

The current configuration is the C3 I²C Jewel/Topaz reader. The bring-up plan tracks remaining bench checks. Flashing and publication require an explicit request.
